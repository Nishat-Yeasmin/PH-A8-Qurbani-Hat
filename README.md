#  Qurbani Hat

A modern Qurbani animal marketplace built with Next.js where users can browse, view details, and book animals for Qurbani.

---

##  Live Demo

 https://qurbanihat-plum.vercel.app

---


---

## ✨ Key Features

-  Featured Animals section
-  All Animals listing page
-  Sort animals by price
-  Animal details page
-  Booking form system
-  Login required for booking
-  My Profile page
-  Update profile (name & image)
-  Responsive UI (mobile + desktop)
-  Fast performance with Next.js

---

##  Tech Stack

- Next.js (App Router)
- React.js
- Tailwind CSS
- Better Auth
- React Toastify
- Node.js (API routes)
